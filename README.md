# gastonfreire.com.ar — V4.2

Bilingual portfolio focused on real career growth, AWS migrations and infrastructure work.

## Included

- Full career journey from Readymind IT to Caylent
- English / Spanish toggle
- Dark / light theme
- 5 real case studies from Netrix Global and Caylent
- Certifications and education
- Kubernetes kept as a complementary skill
- CNAME for gastonfreire.com.ar

## Local preview

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Publish

Copy these files into your existing GitHub Pages repo and run:

```bash
git pull --rebase origin main
git add .
git commit -m "Publish portfolio v4"
git push origin main
```
